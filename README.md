# HelloWorldSwagger

Простой ASP.NET Core Web API проект с поддержкой Swagger.

## Возможности

- ASP.NET Core Web API
- Swagger UI
- REST API

## Технологии

- C#
- .NET 8
- ASP.NET Core
- Swagger / OpenAPI

## Запуск

1. Открыть проект в Visual Studio.
2. Нажать F5.
3. Открыть Swagger по адресу:

https://localhost:<port>/swagger
